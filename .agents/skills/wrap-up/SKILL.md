# Wrap-up

1. Read README.md for required deliverables (file names, sections). They override the defaults below. Never edit README.md.
2. Default submission doc: docs/report.md (Korean), sections:
   - 실행 방법: run command, port, seed data
   - 구현 범위: Must done / not done
   - 핵심 판단과 근거: from the decision log (D-n) and BR-IDs
   - 검증 결과: AC table with pass/fail
   - 남은 한계: open TODOs, deferred changes, known issues
3. Run the verify command; it must pass. Commit.
